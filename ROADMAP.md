# Project Roadmap

This document outlines the planned roadmap and scope for `@chitrank2050/ask-widget` over the next year.

## In Scope (Planned Features)

- **Framework Adapters**: Official wrappers for Vue, Svelte, and Solid.js.
- **Improved Accessibility (a11y)**: Complete keyboard navigation support and screen-reader accessibility audits.
- **Localisation (i18n)**: Support for multi-language localisations.
- **Enhanced Theme Builder**: Interactive playground to generate custom Zinc-palette compatible styling overrides.

## Out of Scope

- **Built-in Backend/DB**: We will not implement custom database adapters or hosting layers; the widget remains backend-agnostic.
- **Proprietary Styling Engines**: We will maintain vanilla CSS layers and will not adopt proprietary runtime CSS-in-JS libraries.
