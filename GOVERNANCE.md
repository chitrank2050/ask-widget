# Project Governance

This document describes the governance model for the `@chitrank2050/ask-widget` project.

## Decision Making Model

The project operates under a single-maintainer model (Benevolent Dictator for Life). All final decisions regarding features, releases, architecture, and contributions are made by the lead maintainer:

- **Lead Maintainer**: Chitrank Agnihotri (@chitrank2050)

## Contributions & RFCs

Community feedback and contributions are welcome. For major changes, we request opening a GitHub Issue as a Request for Comments (RFC) to discuss the design before submitting a pull request.

## Access Continuity

The project is hosted under the `chitranklabs` GitHub organization. Backup administrative access and publishing keys are shared with trusted backup maintainers to ensure project continuity in case the lead maintainer is unavailable.
